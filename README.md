# CampusConnect — Face-Verified Campus Election Portal

Flat single-file deployment ready for **GitHub Pages**, **Netlify Drop**, **Cloudflare Pages**, and **Firebase Hosting**.

## Files
- `index.html` — All-in-one HTML + CSS + Automatic Neural Face Verification + App
- `_redirects` & `_headers` — SPA routing and camera permissions for Netlify & Cloudflare Pages
- `firestore.rules` & `firestore.indexes.json` — Security rules & database indexes for Firebase project `voting-system-cf942`
